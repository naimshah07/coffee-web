# Coffee Shop Website

Welcome to the Coffee Shop Website project — a beautifully designed, fully responsive single-page website for a modern coffee house located in Bernsdorf, Germany. Built with pure HTML, CSS, and JavaScript, this project brings to life an elegant coffee shop experience with warm color tones, smooth animations, and an intuitive user interface that works seamlessly across all device sizes.

## Project Overview

This Coffee Shop website features a complete and polished design that includes every essential section a modern restaurant or cafe website needs. Visitors are greeted with a stunning hero section showcasing the brand's special coffee, followed by a compelling About Us section that shares the story and mission of the coffee house. The menu section displays six carefully curated categories ranging from hot and cold beverages to refreshing drinks, special combos, delicious desserts, and quick bites like burgers and fries. Customer testimonials are presented in a smooth interactive slider, a beautiful gallery section showcases the cafe's ambiance and offerings, and a fully functional contact form makes it easy for guests to reach out with inquiries, feedback, or reservation requests.

## Design & Color Palette

The design follows a warm, inviting color palette dominated by a rich dark brown (#3e1f1f) used across the navigation bar and hero section, perfectly representing the deep tones of roasted coffee beans. A vibrant amber orange (#f59e0b) serves as the primary accent color for buttons, section underlines, and interactive highlights, evoking feelings of warmth, energy, and the comforting aroma of freshly brewed coffee. Light soft pink backgrounds in the main content sections create a gentle contrast that keeps the design airy and welcoming, while the dark charcoal (#1f1f1f) menu section provides an elegant backdrop that makes the colorful food and beverage images truly stand out. Dancing Script cursive font is used for decorative headlines paired with the clean and modern Poppins typeface for body text, creating a sophisticated yet approachable typographic hierarchy.

## Key Features

- **Fully Responsive Layout:** The entire website adapts perfectly to desktop, tablet, and mobile screen sizes with carefully optimized breakpoints at 968px and 640px, ensuring every visitor enjoys a flawless experience regardless of their device.
- **Interactive Testimonial Slider:** A JavaScript-powered slider with navigation arrows and clickable indicator dots allows users to browse customer reviews smoothly with slide transition animations.
- **Sticky Navigation Bar:** The navbar stays fixed at the top of the page while scrolling, with automatic active-link highlighting that updates as users move through different sections.
- **Mobile Hamburger Menu:** On smaller screens, the navigation links collapse into a clean toggleable hamburger menu, keeping the interface clutter-free on mobile devices.
- **Smooth Scrolling:** Clicking any navigation link smoothly scrolls the page to the corresponding section, providing a polished and professional feel.
- **Contact Form Submission:** A validated contact form with name, email, and message fields includes a friendly confirmation alert upon submission.
- **Animated Elements:** The hero section coffee cup image features a subtle floating animation, gallery images have zoom-on-hover effects, and buttons respond with elegant hover transformations.
- **Social Media Integration:** Social icons are placed in both the About section and footer, with hover effects that transition to the brand's accent color.

## Project Structure

The project is organized in a simple, clean structure that makes maintenance and customization straightforward. The root directory contains the main index.html file which holds all the page markup and semantic section structure. The style.css file contains all styling rules including CSS Grid and Flexbox layouts, responsive media queries, keyframe animations, and comprehensive color definitions. The script.js file handles all interactive behavior including slider navigation, mobile menu toggling, smooth scrolling, form handling, and scroll-based active link detection. An images folder contains all visual assets including hero imagery, menu category icons, gallery photos, and user testimonial avatars.

## Technologies Used

This project is built entirely with standard front-end web technologies without any heavy frameworks, keeping it lightweight and fast-loading. HTML5 provides the semantic structural foundation, CSS3 delivers all styling with modern techniques like CSS Grid, Flexbox, custom animations, and responsive media queries. Vanilla JavaScript powers all interactive functionality without dependencies on jQuery or other libraries. The Font Awesome CDN provides the icon library used for navigation, social links, and UI elements, while Google Fonts delivers the Poppins and Dancing Script typefaces.

## How to Use

Getting started is incredibly simple. There are no build tools, dependencies, or installation steps required. Just clone or download the project folder to your local machine, open the index.html file directly in any modern web browser such as Chrome, Firefox, Safari, or Edge, and the website will be fully functional immediately. You can also serve the folder using any simple static file server like VS Code's Live Server extension or Python's built-in http.server module for local development. To customize the website, simply edit the text content directly in the HTML file, adjust colors and layouts in the CSS file, or extend the interactive behavior by adding to the JavaScript file.
